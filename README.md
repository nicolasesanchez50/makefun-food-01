# Midnight Ramen — a program that draws one picture of food

Entry for make.fun's **food-picture-01** ("Make the best-looking food picture").
The picture is a bowl of tonkotsu ramen under a single warm lamp, drawn from
scratch by code — no diffusion model, no photographs, no external assets.

`main.py` writes `art/entry.png` (1024x1024 PNG, ~0.8 MiB) to the harness's
output directory.

## How it is made

`tools/draw_food.py` renders the scene as a 2.5D height field and shades it:

* geometry: the bowl (rim band, inner wall, broth surface with a slow swell),
  two halved soft-boiled eggs with domed jammy yolks, three chashu slices with
  a rolled fat edge, five noodle strands plus a lifted coil, scallion rings,
  chilli-oil droplets and a sheet of nori leaning at the back;
* light: a warm lamp key from the upper left with distance falloff, a cool fill
  from the right, a hot rim light from behind, ambient occlusion from local
  height, a cast shadow on the table and a hard highlight along the near lip;
* lens: bloom on the highlights, a soft reflection lying on the broth, steam
  plumes, shallow depth of field at the edges, vignette and fine grain.

Everything is `numpy` + `Pillow` arithmetic on a 2048x2048 grid, then a single
LANCZOS reduction to 1024x1024. The seed is fixed (`20261114`), so the render is
reproducible byte for byte.

## Running it

```bash
pip install numpy pillow
python3 tools/draw_food.py            # redraw art/entry.png (~35 s)
python3 main.py --check               # validate the shipped PNG (crc, size, dims)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # what the harness does: write entry.png
```

`main.py` is pure standard library. It re-validates the signature, every chunk
CRC, the 1024x1024 bound and the 1 MiB bound, then copies those exact bytes to
`entry.png`; two runs write identical output.
